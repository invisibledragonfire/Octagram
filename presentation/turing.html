Turing Completeness

Turing completeness isn't required to make something a programming language, but it is sufficient. Anything that is turing complete can run theoretically run any program (practically time and memory limit what you can do).

CSS (with HTML) is turing complete

CSS and HTML mostly deal with the structure of the webpage, leaving Javascript to deal with behavior.

However! With modern CSS, you can do computations with just CSS and HTML!

Thus we get state of the art Rule 110 implemented in CSS (explanation) (requires human interaction). Since Rule 110 is Turing complete, this also means CSS+HTML is.
